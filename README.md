# Car Price Prediction Web App

## Folder structure

- app.py
- Cleaned_Car_data.csv
- requirements.txt
- templates/index.html
- static/style.css

## Run locally

1. Open terminal in this folder.
2. Install dependencies:

   pip install -r requirements.txt

3. Start the server:

   python app.py

4. Open this URL in your browser:

   http://127.0.0.1:5000

The app trains the Linear Regression model when the server starts, then accepts user input and displays the predicted price.
